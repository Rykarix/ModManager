## _Notes with the benefit of hindsight_
This was created before the AI era and I must have spent ~3-6 months on this project... the effort rewarded me greatly. 

It contains more code smells than brain cells & and has probably lowered the intelligence of all gh copilot models by a few points but... I think it's a good example of **how** to learn code.

When I started, **I had never**:
- Created an app or worked with any kind of gui
- used code to extract zips or read headers from unfamiliar compression formats in order to extract data
- worked with structured data outside of a few 'how to use python for computational physics' lectures
- completely untrained in programming concepts like dry or solid or design patterns or... whatever they teach computer science grads these days etc etc

... and I gained many hidden benefits, especially in the soft skills dept, that effectively translate to 'how to problem solve' / 'how to diagnose'. It also drastically increased my confidence because (thanks to this project) I felt like I could build anything given enough time. 

If your goal is to learn, consider watching [The Psychology of Intelligence](https://www.youtube.com/watch?v=f1gkkzHZxNg) before using AI for anything and avoid falling prey to the illusion that AI, even 'used well', can speed up learning.

Tl;dr - **Don't be afraid to set yourself an ambitious project and DO NOT use AI to help you.**

# Intro
Since the game does not give you a way to easily enable, disable & organise your mods, I made a tool that makes it much easier.

Future improvements:
- Auto arrange mod load order to save you hours of trial an error
- Information scraping from steam workshop to get mod information. Things like version, updates, images & documentation etc
- Dark mode for tool
- Shortcuts added for tool
- and more
